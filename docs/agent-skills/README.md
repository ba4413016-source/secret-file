# مهارات الوكلاء في «ملف غامض»

أضيفت هذه المجموعة المنتقاة في 25 نوفمبر 2026 داخل `.agents/skills/` بصيغة `SKILL.md`، مع المراجع والبيانات اللازمة لتشغيل المهارات التي لا تعتمد على تكامل خارجي. ثُبّت كل مصدر على commit معلوم لتسهيل المراجعة والتحديث. لا تضمن الشهرة وحدها صحة أي نص؛ اتبع تعليمات المشروع والسياسات والصلاحيات المتاحة، وافحص أي توجيه خارجي قبل تنفيذه.

## المهارات النشطة

- **هندسة وتنفيذ تدريجي:** [incremental-implementation](../../.agents/skills/incremental-implementation/SKILL.md) — شرائح صغيرة قابلة للاختبار، مع مرجع Definition of Done مرفق.
- **الاختبارات:** [test-driven-development](../../.agents/skills/test-driven-development/SKILL.md) — دورة RED/GREEN/REFACTOR، ومعها مرجع أنماط الاختبار لـ JavaScript وTypeScript.
- **مراجعة الكود:** [code-review-and-quality](../../.agents/skills/code-review-and-quality/SKILL.md) — مراجعة الصحة والبنية والأمان والأداء؛ المراجع وقوائم التحقق الضرورية مرفقة.
- **تقوية أمان تطبيقات الويب:** [security-and-hardening](../../.agents/skills/security-and-hardening/SKILL.md) — نمذجة التهديدات، التحقق، المصادقة، الخصوصية، وسلسلة التوريد. مرجع الأنماط وقائمة الأمان مرفقان.
- **تخطيط Red Team المصرّح به:** [security-pentest-planner](../../.agents/skills/security-pentest-planner/SKILL.md) — للتخطيط فقط، ويتطلب تأكيد تفويض كتابي قبل إنشاء خطة. أضيفت حماية تمنع فتح محتوى ملفات `.env*` أو المفاتيح والأسرار؛ تُسجل أسماؤها أو وجودها فقط. لا تنفّذ المهارة هجمات أو اختبارات شبكة. قالبها يحتوي أمثلة اختبار هجومية؛ تعامل مع الخطة الناتجة كمادة حساسة، وراجع النطاق والتفويض قبل أي تنفيذ بشري منفصل.
- **UI/UX:** [ui-ux-pro-max](../../.agents/skills/ui-ux-pro-max/SKILL.md) — حزمة واجهات غنية بالبيانات والإرشادات، وتشمل دعمًا صريحًا لواجهات RTL. نُقلت بياناتها ومراجعها وسكربتاتها كاملة. السكربتات تتطلب Python 3 من المكتبة القياسية فقط ولا تتطلب تثبيت حزم؛ لا تشغّل خيارات `--persist` أو `--preview` قبل تحديد مجلد الإخراج وفحص الملفات الموجودة، ولا تستخدم `--force` إلا بتفويض واضح. عُدّل مسار التشغيل من مسار إضافة Claude إلى موقع المهارة في هذا المستودع.
- **تحرير الصور مع الحفاظ على المصدر:** [image-editing](../../.agents/skills/image-editing/SKILL.md) — نسخة عامة متوافقة مع بيئات الأدوات المختلفة؛ لا تفترض اسم مزود أو واجهة غير متاحة، وتطلب الحفاظ على التفاصيل التي يحددها المستخدم وعدم استبدال التحرير بتوليد جديد دون موافقته.

## تكامل غير مفعّل

توجد نسخة المصدر المتخصصة [SamurAIGPT Image Editing](integrations-pending/image-editing-samurai/agents/image-editing/SKILL.md) تحت `docs/agent-skills/integrations-pending/`، خارج مسار الاكتشاف التلقائي؛ فهي تتطلب اتصال **MuAPI** غير مضبوط في هذا المشروع. أُرفقت خريطة الأدوات والنماذج ومرجع ضمان الجودة كي تكون جاهزة للمراجعة عند إضافة التكامل. دليل النماذج يذكر أن مخططاته فُحصت في 28 أغسطس 2026؛ لا تعتمد على أسماء النماذج أو الأسعار أو الحقول قبل مراجعة المخطط الحي. النسخة العامة النشطة أعلاه لا تحتاج MuAPI.
