# التنسيق وتسليم الواجهة — المرحلة الأولى

## نطاق المرحلة

تجهّز هذه المرحلة واجهة عربية RTL باستخدام Next.js 14 وReact 18 وTypeScript وTailwind CSS. تتضمن الصفحة الرئيسية، نظام التصميم، الترويسة والتنقل، ومسارات توضيحية للقضايا والبحث والملف الشخصي والإعدادات.

محتوى الصفحة الرئيسية بيانات خيالية محلية للمعاينة فقط، ولا تُحفظ. المسارات الأخرى هياكل تنقل وليست ميزات مكتملة.

## حدود التنفيذ

- لا توجد مصادقة أو اتصالات بخدمات خلفية.
- مجلد `supabase/` وملفات مخطط البيانات خارج نطاق الواجهة.
- أصول العلامة محلية؛ لا تُحمّل خطوط أو صور خارجية.
- لا تتضمن هذه المرحلة اختبارات E2E أو Lighthouse؛ لم تُهيأ بعد.

## التحقق المحلي

اجتازت الأوامر `npm run typecheck` و`npm run lint` و`NEXT_TELEMETRY_DISABLED=1 npm run build`. أعادت المسارات `/` و`/cases` و`/search` و`/profile/me` و`/settings` حالة HTTP 200. توجد لقطات معاينة للهاتف وسطح المكتب في `docs/QA_REPORTS/`.

## الوصولية

تدعم الواجهة اتجاه RTL، ومناطق safe-area، والتنقل بلوحة المفاتيح، وتقليل الحركة. إعدادات `maximum-scale=1` و`user-scalable=no` تقلل إمكانية تكبير المحتوى؛ هذا قيد وصولية موثق للمراجعة اللاحقة.
