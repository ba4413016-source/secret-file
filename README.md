# ملف غامض | Secret File

منصة تحقيق تفاعلي عربية، تقدّم قضايا وأدلة وشخصيات في تجربة قصصية مهيأة للأجهزة المحمولة. الواجهة تدعم RTL وتُبنى تدريجيًا لتصبح تطبيق ويب تقدميًا.

> **الحالة:** واجهة المرحلة الأولى قيد التطوير المحلي. الصفحة الرئيسية ونظام التصميم والتنقل متاحة؛ بقية التبويبات هياكل تنقل فقط.

## التقنية

- Next.js 15 App Router وReact 18 وTypeScript strict.
- Tailwind CSS 3 مع رموز تصميم محلية في `app/globals.css`.
- Framer Motion لحركة محدودة في مؤشر التنقل، وLucide React للأيقونات.
- RTL من اليمين إلى اليسار، مع خط النظام ودعم Safe Area.
- لا يوجد ربط بخدمات بيانات أو مصادقة في هذه المرحلة.

## التشغيل المحلي

يتطلب أحد إصدارات Node.js المدعومة من LTS: 22.x أو 24.x أو 26.x.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## الفحوص

```bash
npm run typecheck
npm run lint
npm run build
```

## حدود النسخة الحالية

- بيانات الصفحة في `lib/demo-data.ts` خيالية ومؤقتة، ولا تُحفظ.
- صفحات القضايا والبحث والشخصية والإعدادات توضح التنقل فقط؛ لم تُنفذ ميزاتها بعد.
- لا توجد أسرار أو بيانات اعتماد مطلوبة لتشغيل الواجهة.
- مجلد `supabase/` خارج نطاق عمل الواجهة ولا يُلمس في هذه الجولة.
- إعدادات `maximum-scale=1` و`user-scalable=no` مطبقة حسب المواصفات، وهي تقلل إمكانية تكبير الواجهة.
- بريد الدعم الظاهر في الإعدادات: `ba4413016@gmail.com`.
- تغييرات الواجهة قيد المراجعة؛ لم تُدمج أو تُنشر بعد.
