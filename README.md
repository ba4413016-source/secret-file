# ملف غامض | Secret File

منصة تحقيق تفاعلي عربية، تقدّم قضايا وأدلة وشخصيات في تجربة سينمائية ومهيأة للأجهزة المحمولة. المشروع مخطط ليعمل كتطبيق ويب تقدمي (PWA) مع واجهة عربية من اليمين إلى اليسار.

> **الحالة:** تهيئة المستودع. لم يبدأ تنفيذ التطبيق بعد؛ ستُضاف تعليمات التشغيل عند تجهيز أساس المشروع.

## الرؤية

بناء تجربة تحقيق تفاعلية تجمع جمع الأدلة، تحليل المشتبه بهم، تكوين النظريات، وحل القضايا، مع اهتمام بالخصوصية وإمكانية الوصول وتجربة استخدام عربية واضحة.

## التقنية المخطط لها

- Next.js 14 (App Router) وTypeScript
- Tailwind CSS وواجهة متجاوبة تدعم RTL
- Supabase للمصادقة والبيانات والتخزين والميزات الآنية
- PWA لدعم التثبيت وتجارب الاستخدام الملائمة للأجهزة المحمولة

هذه التقنيات جزء من الخطة، وليست كلها مهيأة في المستودع حاليًا.

## خارطة الطريق

1. **الأساس:** إعداد البنية ونظام التصميم والمصادقة.
2. **القضية الأولى:** بناء دورة تحقيق قابلة للعب وحفظ التقدم.
3. **التوسّع:** البحث والإعدادات والرسائل والمجتمع والمحتوى.
4. **الإطلاق:** الاختبارات، تحسين الوصول والأداء، والتحضير للنشر.

## البدء

لا توجد نسخة قابلة للتشغيل في هذه المرحلة. ستُضاف خطوات التثبيت والإعداد والتشغيل مع تنفيذ التطبيق. لا تضع كلمات مرور أو مفاتيح أو بيانات سرية في المستودع؛ استخدم إعدادات بيئية محلية غير مرفوعة إلى Git.

سيُضاف دليل المساهمة وقواعد العمل عند تجهيز إعدادات المشروع.
